## Direction contract

THESIS: 觀象 owns "the verdict is stamped": every decided thing (吉凶, 宜忌, today's answer, where you are) arrives as a carved seal impression, the way a reading was authorised on paper. It refuses the category default of a dark mystic starfield with glowing gradients and thirteen differently-coloured theme skins.

OWN-WORLD: seal-carving studio. Cool 宣紙 ground (light) / 墨 ground (night), white sheets with hairline rules, ink-black top bar. 印泥 vermilion owns 吉/宜/selection/primary action; solid ink owns 凶/忌. Per-method mineral pigment (石綠, 石青, 胭脂, 花青, 赭石, 紫) colours only that page's header seal. Square seals with 3px corners, Noto Serif TC 900 for seal glyphs, Song serif headings, 楷書 (LXGW WenKai TC) for classical text, system sans for prose. Drawn SVG tab icons.

STORY: someone opens it on a phone in the morning, sees today's date, the 宜/忌 seals and their own outlook at a glance, then taps a tab to ask a question and gets a stamped verdict with plain advice and visible sources.

FIRST VIEWPORT: phone 390px. Ink top bar (vermilion 觀象 seal, left). Today sheet: huge vermilion day numeral, 農曆 and 干支 beside it; 宜 seal (vermilion) and 忌 seal (ink) each heading a row of chips; four primary actions as a 2x2 button grid. Bottom tab bar: 今日 卜卦 求籤 塔羅 全部, current tab's icon stamped in a vermilion square. 全部 opens a grouped sheet (問事 / 日子 / 命盤 / 查閱). Desktop: same, grouped nav inline in the top bar, content column 760px.

FORM: Seal-carving (篆刻) world, candidate 6 of my ordered list (1 農民曆 two-colour print, 2 廟宇籤紙, 3 水墨宣紙, 4 線裝古籍, 5 石刻天文圖拓本, 6 篆刻朱印, 7 月相夜空). seed:2ff563e1d9349e4a. Signature move: 落印, a seal stamps in (scale 1.3 to 1, slight rotation, blur clearing, exponential ease-out) when a verdict or page seal appears; reduced motion shows it already stamped. Raises from declined challengers: type specimen → hierarchy by scale contrast (huge numerals, tiny labels); metro tiles → chrome deleted where type can do it; character catalog → every person row carries the same fixed furniture; zoo map → one dominant area per screen; acetate manual → section hue per method; ticket wallet → states stamp themselves, nothing silently disappears.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
